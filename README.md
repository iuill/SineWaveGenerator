# Audio Wave Generator

周波数・波形・左右チャンネル・音量を選んで再生できるブラウザ音声ツールです。補助機能として、補聴器の左右の聞こえ方を記録して相談メモにまとめる「かんたん測定」も搭載しています。

## 自由再生（メイン機能）

- 25～8000 Hzの周波数選択
- 正弦波・方形波・三角波・ノコギリ波
- 左右・左のみ・右のみの出力
- アプリ内部音量を0～100%で調整
- 再生中の周波数・波形・チャンネル・音量変更

## かんたん測定（補助機能）

- 低音（500 Hz）・中音（2 kHz）・高音（4 kHz）の聞き比べ
- 補聴器調整の入力50 / 65 / 80 dBに相当する3段階のレベル差（実音圧は未校正）
- 測定前の基準音量プレビュー
- かんたん測定の基準音量を最大100%まで調整
- 回答すると次の項目へ進む案内型の測定フロー
- 左右差が見つかった音域の低い側・高い側を1周波数ずつ確認する詳細測定
- 大きく感じる側を減衰させて知覚的な左右差を1 dB刻みで記録する補正目安
- 左のみ・右のみ・左右交互の再生
- 左右差、聞こえにくさ、不快感の記録
- 測定結果の一覧表示
- 補聴器の調整担当者へ見せる相談メモの自動生成
- メモのコピーとテキスト保存
- 複数の測定結果をブラウザ内へ個別に自動保存
- 保存した測定の表示切り替えと個別削除

## 使い方

`index.html` をブラウザで開きます。音が突然大きくならないよう、最初に端末側の音量と画面上の基準音量を低く設定してください。

## 注意

このアプリは、校正された聴力検査や補聴器適合検査を行うものではありません。表示される音量は端末内での相対値であり、dB SPLではありません。結果は感じ方を専門家へ伝える補助資料として使用し、補聴器の設定変更は専門家に相談してください。
